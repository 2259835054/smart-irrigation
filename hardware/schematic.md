## 文档概述

本文档详细说明智能灌溉系统各功能模块的电路原理，包括电路设计思路、元件选型、PCB 布局建议。

## 2. 电源部分电路

### 2.1 电源架构

```
输入：5V DC 3A
   │
   ├──→ ESP32 开发板 VIN
   │        │
   │        └──→ AMS1117 (LDO) ──→ 3.3V 输出
   │                                   │
   │                                   ├──→ ESP32 核心
   │                                   ├──→ DHT22 (3.3V)
   │                                   ├──→ OLED (3.3V)
   │                                   └──→ 土壤传感器 (3.3V)
   │
   ├──→ MOS管模块 V+ ──→ 水泵 (5V)
   │
   └──→ 蜂鸣器 (5V)
```

### 2.2 电源原理图（简化）

```
      5V 输入
        │
        ├───────────────┬─────────────┬────────────┐
        │               │             │            │
        ↓               ↓             ↓            ↓
   ┌────────┐      ┌────────┐   ┌────────┐   ┌────────┐
   │ ESP32  │      │ MOS1   │   │ MOS2   │   │ MOS3   │
   │ VIN    │      │ V+     │   │ V+     │   │ V+     │
   └───┬────┘      └───┬────┘   └───┬────┘   └───┬────┘
       │               │            │            │
       │ AMS1117       │            │            │
       ├─→ 3.3V        │            │            │
       │               │            │            │
       │          ┌────┴────┐  ┌────┴────┐  ┌────┴────┐
       │          │  水泵1   │  │  水泵2   │  │  水泵3   │
       │          └────┬────┘  └────┬────┘  └────┬────┘
       │               │            │            │
       └───────────────┴────────────┴────────────┴───→ GND
```

**元件参数**：
- **AMS1117-3.3**：LDO 稳压器，输入 4.5-12V，输出 3.3V，最大 1A
- **电容**：输入 10μF + 输出 22μF（去耦）

### 2.3 电源保护建议

```
         5V 输入
           │
       ┌───┴───┐
       │ F1    │ 保险丝 3A
       └───┬───┘
           │
       ┌───┴───┐
       │ D1    │ 反向保护二极管（肖特基）
       └───┬───┘
           │
       ┌───┴───┐
       │ C1    │ 滤波电容 1000μF
       └───┬───┘
           │
          后级电路
```

**推荐元件**：
- **F1**：自恢复保险丝 3A（PPTC）
- **D1**：肖特基二极管 SS34（3A 40V）
- **C1**：电解电容 1000μF 16V

## 3. 传感器电路

### 3.1 电容式土壤湿度传感器电路

**单通道原理图**：
```
       3.3V
         │
    ┌────┴────┐
    │ 土壤湿度 │ 电容式传感器
    │ 传感器   │ (内部振荡电路)
    └────┬────┘
         │ AOUT (0-3.3V 模拟输出)
         │
         ├────────────→ ESP32 GPIO 34 (ADC1_CH6)
         │
     ┌───┴───┐
     │ 0.1μF │ 旁路电容（可选，抑制噪声）
     └───┬───┘
         │
        GND
```

**4 通道完整接线**：
- 通道1 AOUT → GPIO 34 (ADC1_CH6)
- 通道2 AOUT → GPIO 35 (ADC1_CH7)
- 通道3 AOUT → GPIO 32 (ADC1_CH4)
- 通道4 AOUT → GPIO 33 (ADC1_CH5)

**工作原理**：
1. 传感器内部震荡电路产生高频信号
2. 电容极板与土壤形成电容
3. 土壤湿度越高，电容值越大，输出电压越低
4. ESP32 ADC 读取电压并转换为湿度百分比

**ADC 配置**：
- 分辨率：12-bit（0-4095）
- 参考电压：3.3V
- 采样次数：10 次（中值滤波）

### 3.2 DHT22 温湿度传感器电路

**原理图**：
```
       3.3V
         │
    ┌────┴────┐ ┌────────┐
    │ 4.7kΩ   │ │ DHT22  │
    │ 上拉电阻 │ │        │
    └────┬────┘ │ Pin1 VCC ───→ 3.3V
         │      │ Pin2 DATA ───→ GPIO 4
         ├──────┤ Pin3 NC
         │      │ Pin4 GND ────→ GND
         │      └────────┘
         │
    ESP32 GPIO 4
```

**工作原理**：
1. DHT22 使用单总线协议（1-Wire）
2. ESP32 通过时序控制读取数据
3. 数据格式：40-bit（湿度高8位+湿度低8位+温度高8位+温度低8位+校验和）
4. 上拉电阻保证总线空闲时为高电平

**注意**：
- 采样间隔 ≥ 2 秒
- 启动信号：拉低 >1ms
- 响应信号：80μs 低电平 + 80μs 高电平

### 3.3 光照传感器电路

**方案1：BH1750（I2C 数字传感器）**：
```
       3.3V
         │
    ┌────┴────┐
    │ BH1750  │ I2C 光照传感器
    │         │
    │ VCC ────┼──→ 3.3V
    │ GND ────┼──→ GND
    │ SCL ────┼──→ GPIO 22 (与OLED共享)
    │ SDA ────┼──→ GPIO 21 (与OLED共享)
    │ ADDR ───┼──→ GND (I2C地址 0x23)
    └─────────┘
```

**方案2：光敏电阻（模拟传感器）**：
```
       3.3V
         │
    ┌────┴────┐
    │  10kΩ   │ 固定电阻
    │         │
    └────┬────┘
         │
         ├──────────→ ESP32 GPIO 36 (ADC)
         │
    ┌────┴────┐
    │  光敏   │ 阻值随光照变化
    │  电阻   │ (暗：1MΩ，亮：几kΩ)
    └────┬────┘
         │
        GND
```

**光敏电阻分压计算**：
```
Vout = 3.3V × R_光敏 / (10kΩ + R_光敏)

暗处（R=1MΩ）：Vout ≈ 3.3V
亮处（R=1kΩ）：Vout ≈ 0.3V
```

### 3.4 水位传感器电路

**原理图**：
```
       3.3V
         │
    ┌────┴────┐
    │ 内部上拉 │ (ESP32 GPIO 内部)
    │  10kΩ   │
    └────┬────┘
         │
         ├──────────→ ESP32 GPIO 5
         │
    ┌────┴────┐
    │ 浮球开关 │ 常开型（NO）
    │  COM-NO │
    └────┬────┘
         │
        GND

水位正常：浮球上浮，触点闭合，GPIO 5 = LOW
水位不足：浮球下沉，触点断开，GPIO 5 = HIGH (上拉)
```

**防抖处理**（软件实现）：
- 连续 3 次读取稳定值才确认状态
- 间隔 50ms 采样

## 4. 执行器电路

### 4.1 水泵 MOS管驱动电路

**单路完整电路**：
```
ESP32 GPIO 16 (PWM)
    │
    ├────────┬──→ MOS管模块 SIG
    │        │
    │    ┌───┴───┐
    │    │ 1kΩ  │ 下拉电阻（防止浮空）
    │    └───┬───┘
    │        │
    │       GND
    │
    MOS管模块内部：
    
    SIG ──┬───────→ R1 (1kΩ) ──→ MOSFET Gate
          │
          └───────→ R2 (10kΩ) ──→ GND (下拉)
          
    5V ───→ MOSFET Drain ───→ 水泵正极
    
    MOSFET Source ───→ 水泵负极 ───→ GND
```

**MOS管选型**：
- **IRF520**：N-MOSFET，100V 9.2A，Rds(on)=0.27Ω
- **IRF540**：N-MOSFET，100V 28A，Rds(on)=0.077Ω（推荐）

**工作原理**：
1. ESP32 输出 PWM 信号（0-3.3V）
2. MOS管栅极电压 > 阈值电压（约 2V）时导通
3. 漏极到源极导通，水泵得电运行
4. PWM 占空比控制水泵平均功率（调速）

**PWM 参数**：
- 频率：5000 Hz
- 分辨率：8-bit（0-255）
- 占空比：0%（停止）~ 100%（全速）

### 4.2 蜂鸣器驱动电路

**方案1：直接驱动（GPIO 电流足够）**：
```
ESP32 GPIO 23
    │
    ├──────┬──→ 蜂鸣器正极
    │      │
    │  ┌───┴───┐
    │  │ 100Ω │ 限流电阻（可选）
    │  └───┬───┘
    │      │
    │  ┌───┴───┐
    │  │ 蜂鸣器 │ 5V 有源蜂鸣器
    │  └───┬───┘
    │      │
    │     GND
```

**方案2：三极管放大驱动（推荐）**：
```
ESP32 GPIO 23
    │
    ├──────┬──→ R1 (1kΩ) ──→ NPN 三极管基极 (S8050)
    │      │
    │      └──→ R2 (10kΩ) ──→ GND (基极下拉)
    │
    三极管集电极 ←──── 蜂鸣器正极 ←──── 5V
    三极管发射极 ────→ GND
```

**NPN 三极管参数**：
- **S8050**：NPN，Vce=25V，Ic=500mA，hFE=120-200
- **2N2222**：NPN，Vce=40V，Ic=800mA（替代）

### 4.3 LED 指示电路

**原理图**：
```
ESP32 GPIO 2
    │
    ├────────→ R (220Ω) ──→ LED 正极 ──→ GND
    │                          │
    │                      ┌───┴───┐
    │                      │  LED  │ 3mm/5mm
    │                      └───────┘
```

**限流电阻计算**：
```
R = (V_gpio - V_led) / I_led
  = (3.3V - 2.0V) / 10mA
  = 130Ω

推荐使用 220Ω（标准阻值，电流约 6mA）
```

**LED 参数**：
- 红色：正向压降 1.8-2.0V，电流 10-20mA
- 蓝色/白色：正向压降 2.8-3.2V，电流 10-20mA

### 5.2 按键电路

**原理图**：
```
       3.3V
         │
    ┌────┴────┐
    │ 内部上拉 │ ESP32 GPIO 内部 10kΩ
    │  10kΩ   │
    └────┬────┘
         │
    ESP32 GPIO 15 ────┬──→ 按键（模式）

```
       3.3V
         │
    ┌────┴────┐

         │

## 6. PCB 设计建议

### 6.1 PCB 层叠结构

**2 层板推荐**（成本低）：
```
顶层 (Top Layer)：
  - ESP32 开发板排针
  - 传感器接口端子
  - MOS管模块接口

底层 (Bottom Layer)：
  - 完整接地铜皮（GND 平面）
  - 5V 电源走线
```

**4 层板推荐**（专业版）：
```
Layer 1 (Top)：信号走线
Layer 2：GND 平面
Layer 3：VCC 平面（3.3V + 5V）
Layer 4 (Bottom)：信号走线
```

### 6.2 布局建议

**分区布局**：
```
┌────────────────────────────────────────────┐
│                                            │
│  ┌──────────┐       ┌──────────┐          │
│  │ 电源区域  │       │ 控制区域  │          │
│  │ DC接口   │       │  ESP32   │          │
│  │ 保险丝   │       │  开发板  │          │
│  └──────────┘       └──────────┘          │
│                                            │
│  ┌──────────────────────────────┐          │
│  │      传感器接口区             │          │
│  │  湿度×4 | DHT22 | 光照 | 水位 │          │
│  └──────────────────────────────┘          │
│                                            │
│  ┌──────────────────────────────┐          │
│  │      执行器接口区             │          │
│  │  MOS×4 | 蜂鸣器 | LED        │          │
│  └──────────────────────────────┘          │
│                                            │
│  ┌──────────┐       ┌──────────┐          │
│  │ OLED显示 │       │ 按键     │          │
│  └──────────┘       └──────────┘          │
└────────────────────────────────────────────┘
```

### 6.3 走线规则

**电源走线**：
- 5V 主电源：线宽 ≥ 1.5mm（3A 电流）
- 3.3V 电源：线宽 ≥ 0.8mm（500mA 电流）
- GND 走线：线宽 ≥ 1.5mm 或完整铜皮

**信号走线**：
- 数字 I/O：线宽 0.2-0.3mm
- I2C 信号（SDA/SCL）：线宽 0.3mm，等长布线
- ADC 信号：远离高频信号，加地线隔离

**高频走线**：
- WiFi 天线保持区：周围 5mm 内无走线和铜皮
- PWM 信号：远离 ADC 输入

### 6.4 去耦电容放置

**电源去耦**：
```
ESP32 附近：
  - VCC → 100nF (0.1μF) → GND（靠近引脚）
  - VCC → 10μF → GND（稍远）

传感器接口：
  - 每个传感器 VCC 引脚附近放置 0.1μF 电容

水泵电源：
  - 5V 主电源输入：1000μF 电解电容（吸收启动尖峰）
```

### 6.5 接地设计

**单点接地**：
```
         ┌──── 传感器 GND
         │
         ├──── ESP32 GND
         │
GND ─────┼──── OLED GND
(单点)   │
         ├──── 水泵电源 GND
         │
         └──── 按键 GND
```

**地平面覆铜**：
- 顶层和底层都覆铜
- 通过多个过孔连接
- 避免地线环路

## 8. 常见问题与改进

### Q1：ADC 读数噪声大

**原因**：
- 电源纹波
- 信号线受干扰
- 接地不良

**解决方案**：
1. 在 ADC 输入引脚添加 RC 低通滤波：
   ```
   AOUT ──→ 1kΩ ──┬──→ GPIO 34
                  │
              ┌───┴───┐
              │ 0.1μF │
              └───┬───┘
                  │
                 GND
   ```
2. 使用滑动窗口中值滤波（软件实现）
3. 完整接地平面

### Q2：水泵启动时系统复位

**原因**：
- 水泵启动瞬间电流大（浪涌）
- 电源电压跌落

**解决方案**：
1. 在 5V 电源输入端添加大电容（1000-2200μF）
2. 使用功率更大的电源适配器（5V 5A）
3. 水泵分时启动（避免 4 个同时启动）

### Q3：WiFi 连接不稳定

**原因**：
- 天线附近有金属遮挡
- 电源纹波干扰 WiFi 模块

**解决方案**：
1. WiFi 天线区域保持净空（5mm 范围内无铜皮）
2. ESP32 VCC 引脚添加 10μF + 0.1μF 去耦电容
3. 使用外部天线（IPEX 接口）

## 9. 成本优化方案

### 9.1 低成本版本（约 120 元）

**简化方案**：
- 使用光敏电阻替代 BH1750（省 3 元）
- 使用 DHT11 替代 DHT22（省 5 元）
- 使用 0.91" OLED 替代 0.96"（省 2 元）
- 省略蜂鸣器（省 2 元）
- 使用面包板搭建，不定制 PCB（省 20 元）

### 9.2 增强版本（约 250 元）

- 太阳能板 + 18650 锂电池 + 充电模块（+60 元）
- LoRa 无线模块（替代 WiFi，适合户外）（+20 元）
- 定制 PCB + 外壳（+30 元）

## 10. 总结

本智能灌溉系统电路设计的核心要点：

### 关键技术

1. **模拟信号处理**：ADC 采样 + 中值滤波
2. **数字通信**：I2C（OLED）、单总线（DHT22）
3. **PWM 控制**：MOS管驱动水泵调速
4. **电源管理**：5V/3.3V 双电源架构

### 设计亮点

- ✅ **低功耗**：Deep Sleep 模式下 < 10μA
- ✅ **高可靠**：多重安全保护（超时、缺水、过流）
- ✅ **易扩展**：模块化设计，预留接口
- ✅ **低成本**：总成本 150 元左右

### PCB 设计建议

- 2 层板即可满足需求（成本低）
- 分区布局，模拟数字分离
- 完整接地平面，多点去耦
- 预留测试点和扩展接口
