## 供电系统设计

### 主电源

系统采用 **5V 2A 电源适配器** 供电。

```
         AC 220V
            |
      ┌─────┴─────┐
      │  电源适配器 │
      │  5V / 2A  │
      └─────┬─────┘
            |
       5V ──┴── GND
            |
     ┌──────┴──────┐
     │             │
  ESP32 VIN    水泵驱动模块
     │             │
  (内部LDO)    直接供电
     │
   3.3V
     │
   传感器
```

### 电压分配

| 模块 | 供电电压 | 电流消耗 | 供电来源 |
|------|---------|---------|---------|
| ESP32 核心 | 3.3V | 80-200mA | ESP32 内部 LDO (5V→3.3V) |
| WiFi 模块 | 3.3V | 80-170mA | ESP32 内部供电 |
| 土壤湿度传感器 | 3.3V | 5mA | ESP32 3.3V 输出 |
| DHT22 | 3.3V | 1.5mA | ESP32 3.3V 输出 |
| OLED (SSD1306) | 3.3V | 20mA | ESP32 3.3V 输出 |
| 水位传感器 | 5V | 5mA | ESP32 5V 输出 |
| 水泵 | 5V | 150-300mA | 独立 5V 供电 |
| MOS 驱动模块 | 5V | 5mA | 独立 5V 供电 |
| 蜂鸣器 | 3.3V | 30mA | GPIO 直接驱动 |
| LED | 3.3V | 10-20mA | GPIO + 限流电阻 |

**总功耗估算**：
- 待机功耗：约 0.5W (100mA @ 5V)
- 水泵工作时：约 2.0W (400mA @ 5V)

## 各模块电路设计

### 1. 土壤湿度检测电路

电容式土壤湿度传感器通过电容变化检测土壤含水量。

```
        ESP32
    ┌──────────┐
    │          │
    │ 3.3V ────┼────> 传感器 VCC
    │          │            ┌─────────┐
    │ GPIO 34 <┼──────<─ AOUT│ 电容式  │
    │   (ADC)  │            │土壤湿度 │
    │ GND ─────┼────> GND   │ 传感器  │
    │          │            └─────────┘
    └──────────┘
```

**工作原理**：
- 传感器输出 0-3.3V 模拟电压
- ESP32 ADC 读取电压值（0-4095）
- 土壤湿润：电容大，输出电压低
- 土壤干燥：电容小，输出电压高

**ADC 配置**：
- 分辨率：12-bit (0-4095)
- 参考电压：3.3V
- 转换公式：湿度% = map(ADC_value, 4095, 0, 0, 100)

---

### 2. DHT22 温湿度检测电路

DHT22 使用单总线协议通信，需要上拉电阻。

```
        ESP32
    ┌──────────┐
    │          │        3.3V
    │ 3.3V ────┼────┬──> VCC
    │          │    │       ┌─────────┐
    │          │   [4.7kΩ] │         │
    │ GPIO 4 <─┼────┴──<─ DATA DHT22 │
    │          │            │         │
    │ GND ─────┼──────> GND │         │
    │          │            └─────────┘
    └──────────┘
```

**上拉电阻说明**：
- 阻值：4.7kΩ（推荐）或 10kΩ
- 作用：确保数据线空闲时为高电平
- 某些 DHT22 模块内置上拉电阻

**时序要求**：
- 起始信号：主机拉低至少 1ms
- DHT22 响应：拉低 80μs，拉高 80μs
- 数据传输：40 位数据（16 位湿度 + 16 位温度 + 8 位校验）

---

### 3. 水位检测电路

浮球式水位开关，内部是磁簧开关。

```
        ESP32
    ┌──────────┐
    │          │
    │ 5V ──────┼────> VCC
    │          │           ┌──────────┐
    │ GPIO 5 <─┼────< OUT  │ 浮球式   │
    │ (INPUT_  │           │ 水位传感器│
    │  PULLUP) │           │          │
    │ GND ─────┼────> GND  └──────────┘
    │          │
    └──────────┘
```

**工作原理**：
- 有水时：浮球上浮，磁簧开关闭合，输出 LOW
- 缺水时：浮球下沉，磁簧开关断开，输出 HIGH（上拉）

**安装位置**：
- 安装在水箱底部或侧面
- 确保浮球可以自由移动

---

### 4. 水泵驱动电路

**关键设计要点**：
- ⚠️ **水泵不能直接连接 ESP32 GPIO！**
- GPIO 输出电流最大 20-40mA，而水泵需要 150-300mA
- 必须使用驱动模块（MOS 管或继电器）

#### 方案 A：MOS 管驱动（推荐）

```
        ESP32                   MOS 驱动模块              水泵
    ┌──────────┐            ┌───────────────┐
    │          │            │               │        ┌────────┐
    │ GPIO 16 ─┼────────> IN│   [MOS管]     │V+──>+│ 微型   │
    │          │            │      |        │       │ 潜水泵 │
    │          │            │      |        │V───>-│        │
    │          │            └──┬───┴────────┘       └────────┘
    │          │               │            
    └──────────┘               │            
         │                     │            
        GND <──────────────────┴──> GND    
                              (共地)

      5V 电源 (+) ───────> MOS 模块 VCC
      5V 电源 (-) ───────> MOS 模块 GND
```

**MOS 管工作原理**：
- GPIO 16 输出 HIGH (3.3V)：MOS 管导通，水泵通电
- GPIO 16 输出 LOW (0V)：MOS 管截止，水泵断电

**优点**：
- ✅ 静音无噪音
- ✅ 开关速度快
- ✅ 寿命长
- ✅ 可以 PWM 调速

#### 方案 B：继电器驱动

```
        ESP32              继电器模块              水泵
    ┌──────────┐      ┌────────────┐
    │          │      │            │          ┌────────┐
    │ GPIO 16 ─┼──> IN│  [继电器]   │COM ─ 5V+ │        │
    │          │      │            │NO ────>+│ 微型   │
    │ 5V ──────┼──> VCC           │          │ 潜水泵 │
    │ GND ─────┼──> GND           │       ->-│        │
    │          │      └────────────┘       │  └────────┘
    └──────────┘                           │
                                          GND
```

**继电器工作原理**：
- GPIO 16 输出 HIGH：继电器线圈通电，触点闭合，水泵通电
- GPIO 16 输出 LOW：继电器线圈断电，触点断开，水泵断电

**优点**：
- ✅ 价格便宜
- ✅ 电气隔离

**缺点**：
- ❌ 有机械触点，有吸合声音
- ❌ 寿命相对较短（约 10 万次）

### 5. OLED 显示电路

OLED 使用 I2C 接口，只需 4 根线。

```
        ESP32                 OLED (SSD1306)
    ┌──────────┐            ┌───────────────┐
    │          │            │               │
    │ 3.3V ────┼─────────> VCC 128x64 I2C  │
    │          │            │               │
    │ GPIO 22 ─┼────────> SCL (时钟线)     │
    │  (SCL)   │            │               │
    │ GPIO 21 ─┼────────> SDA (数据线)     │
    │  (SDA)   │            │               │
    │ GND ─────┼─────────> GND             │
    │          │            │               │
    └──────────┘            └───────────────┘
```

**I2C 配置**：
- 地址：0x3C（某些模块是 0x3D）
- 速度：400kHz（快速模式）
- 上拉电阻：ESP32 内部上拉或 OLED 模块自带

**显示内容布局**：
```
┌──────────────────────────┐
│ == Smart Irrigation ==   │ <- 标题栏 (行0)
│ Soil: 75%                │ <- 土壤湿度 (行12)
│ Temp: 24.5C              │ <- 温度 (行22)
│ Humi: 60%                │ <- 湿度 (行32)
│ Tank: OK                 │ <- 水箱状态 (行42)
│ Pump:ON [Auto]           │ <- 水泵和模式 (行52)
└──────────────────────────┘
```

### 6. 按键输入电路

简单的上拉输入，按下时接地。

```
        ESP32
    ┌──────────┐
    │          │
    │ GPIO 15 ─┼────┬─────┐
    │ (INPUT_  │    │     │
    │  PULLUP) │   [ ]    │
    │          │   按键   │
    │ GND ─────┼────┴─────┘
    │          │
    └──────────┘
```

**工作原理**：
- 松开时：GPIO 15 被内部上拉到 3.3V (HIGH)
- 按下时：GPIO 15 接地 (LOW)

**软件消抖**：
- 延迟 300ms 消除机械抖动
- 长按检测：2000ms 阈值

---

### 7. LED 指示灯电路

GPIO 驱动 LED，需要限流电阻。

```
        ESP32
    ┌──────────┐
    │          │
    │ GPIO 2 ──┼───[220Ω]──>|───┐
    │          │           LED  │
    │ GND ─────┼────────────────┘
    │          │
    └──────────┘
```

**限流电阻计算**：
- LED 正向压降：约 2V (红光 LED)
- GPIO 输出电压：3.3V
- LED 电流：10mA (安全值)
- 电阻值：R = (3.3V - 2V) / 10mA = 130Ω
- 选用标准值：**220Ω**（更安全）

---

### 8. 蜂鸣器电路

有源蜂鸣器，直接 GPIO 驱动。

```
        ESP32
    ┌──────────┐
    │          │         ┌────┐
    │ GPIO 17 ─┼────────>│ +  │ 蜂鸣器
    │          │         │ -  │ (有源)
    │ GND ─────┼────────>└────┘
    │          │
    └──────────┘
```

**注意事项**：
- 使用有源蜂鸣器（内置振荡器），3.3V 即可驱动
- 电流约 30mA，GPIO 可直接驱动
- 如果电流过大，可以加三极管驱动电路

## PCB 布局建议

如果要制作 PCB，建议布局如下：

```
┌─────────────────────────────────────┐
│                                     │
│  ┌──────────┐        ┌──────┐      │
│  │  ESP32   │        │ OLED │      │
│  │          │        └──────┘      │
│  │          │                      │
│  └──────────┘                      │
│                                     │
│  [按键]  [LED]  [蜂鸣器]             │
│                                     │
│  ┌─────────┐   ┌──────────┐        │
│  │ MOS驱动 │   │ 传感器    │        │
│  │  模块   │   │ 接口端子   │        │
│  └─────────┘   └──────────┘        │
│                                     │
│  [DC接口 5V]                         │
└─────────────────────────────────────┘
```

**布局要点**：
- 数字电路和模拟电路分开
- 传感器接口靠边，方便接线
- 水泵驱动远离传感器，避免干扰
- 电源线和地线加粗

## 电路保护措施

### 1. 过流保护
在 5V 电源输入端串联保险丝或自恢复保险丝：
```
5V 输入 ──[保险丝 1A]── 系统供电
```

### 2. 防反接保护
在电源输入端加二极管或 PMOS：
```
5V ──>|─── 系统
    二极管
```

### 3. ESD 保护
在传感器输入端加 TVS 二极管保护。

### 4. 续流保护
水泵驱动电路中 MOS 管或继电器需要并联续流二极管，防止反向电动势损坏器件。

## 常见问题与解决方案

### Q1: ESP32 频繁重启？
- **原因**：供电不足，水泵启动瞬间电流过大
- **解决**：加大电源容量，或加电解电容滤波（1000μF）

### Q2: ADC 读数不稳定？
- **原因**：WiFi 开启时影响 ADC 精度
- **解决**：多次采样取平均值，或关闭 WiFi 时读取

### Q3: I2C 设备不响应？
- **原因**：上拉电阻缺失或地址错误
- **解决**：检查上拉电阻，使用 I2C 扫描工具确认地址
