# 接线说明文档

## 文档概述

本文档详细说明智能灌溉系统的完整接线方法，包括传感器、执行器、显示屏、按键的连接，以及注意事项和常见问题。

## 1. ESP32 引脚分配表

### 完整引脚映射

| ESP32 引脚 | 功能 | 连接设备 | 类型 | 备注 |
|-----------|------|---------|------|------|
| **GPIO 34** | 土壤湿度1 | 电容式土壤传感器1 | ADC1_CH6（输入） | 仅输入，无上拉 |
| **GPIO 35** | 土壤湿度2 | 电容式土壤传感器2 | ADC1_CH7（输入） | 仅输入，无上拉 |
| **GPIO 32** | 土壤湿度3 | 电容式土壤传感器3 | ADC1_CH4（输入） | ADC1 通道 |
| **GPIO 33** | 土壤湿度4 | 电容式土壤传感器4 | ADC1_CH5（输入） | ADC1 通道 |
| **GPIO 4** | DHT22 数据 | DHT22 温湿度传感器 | 数字 I/O | 需 4.7kΩ 上拉 |
| **GPIO 5** | 水位检测 | 浮球水位传感器 | 数字输入 | 内部上拉 |
| **GPIO 36** | 光照传感器 | BH1750 或光敏电阻 | ADC1_CH0（输入） | 仅输入 |
| **GPIO 16** | 水泵1控制 | MOS管模块1 SIG | PWM 输出 | LEDC 通道0 |
| **GPIO 17** | 水泵2控制 | MOS管模块2 SIG | PWM 输出 | LEDC 通道1 |
| **GPIO 18** | 水泵3控制 | MOS管模块3 SIG | PWM 输出 | LEDC 通道2 |
| **GPIO 19** | 水泵4控制 | MOS管模块4 SIG | PWM 输出 | LEDC 通道3 |
| **GPIO 2** | LED 指示灯 | LED（串220Ω电阻） | 数字输出 | 板载 LED |
| **GPIO 23** | 蜂鸣器 | 5V 有源蜂鸣器 | 数字输出 | 报警提示 |
| **GPIO 15** | 模式按键 | 轻触开关 | 数字输入 | 内部上拉 |
| **GPIO 13** | 选择按键 | 轻触开关 | 数字输入 | 内部上拉 |
| **GPIO 21** | I2C SDA | OLED SDA | I2C 数据 | 需外部上拉（OLED模块已集成） |
| **GPIO 22** | I2C SCL | OLED SCL | I2C 时钟 | 需外部上拉（OLED模块已集成） |
| **3.3V** | 电源输出 | 传感器 VCC | 电源 | 最大输出约 500mA |
| **5V (VIN)** | 电源输入 | 外部 5V 电源 | 电源 | 供电给 ESP32 |
| **GND** | 地线 | 所有模块 GND | 地线 | 公共地 |

### 关键引脚说明

**ADC1 通道（推荐用于模拟传感器）**：
- GPIO 32, 33, 34, 35, 36, 39 — WiFi 开启时仅 ADC1 可用
- **注意**：GPIO 34-39 仅支持输入，无内部上拉电阻

**不可用引脚**：
- GPIO 0：BOOT 按键，启动时下拉会进入下载模式
- GPIO 6-11：连接 Flash，禁止使用
- GPIO 12：启动时必须为低电平

## 2. 分模块接线说明

### 2.1 传感器接线

#### A. 电容式土壤湿度传感器（×4）

**传感器1接线**：
```
传感器1          ESP32
────────        ────────
VCC      ───→   3.3V 或 5V（根据传感器规格）
GND      ───→   GND
AOUT     ───→   GPIO 34
```

**传感器2/3/4 接线**：
- 传感器2 AOUT → GPIO 35
- 传感器3 AOUT → GPIO 32
- 传感器4 AOUT → GPIO 33

**注意事项**：
- VCC 根据传感器型号选择 3.3V 或 5V（大部分支持 3.3-5V）
- AOUT 输出电压必须 ≤ 3.3V（ESP32 ADC 耐压上限）
- 传感器插入土壤深度约 5-7cm
- 避免传感器长时间浸水

#### B. DHT22 温湿度传感器

**模块版接线**（推荐）：
```
DHT22模块       ESP32
────────        ────────
VCC      ───→   3.3V 或 5V
GND      ───→   GND
DATA     ───→   GPIO 4
```

**裸传感器接线**（需外接上拉电阻）：
```
DHT22            ESP32
────────         ────────
Pin 1 (VCC) ───→ 3.3V 或 5V
Pin 2 (DATA)───→ GPIO 4 ─┐
Pin 3 (NC)      （悬空）   │
Pin 4 (GND)────→ GND      │
                          │
                     ┌────┴────┐
                     │ 4.7kΩ  │ 上拉电阻
                     │         │
                     └────┬────┘
                          │
                         VCC
```

**注意事项**：
- DHT22 采样间隔最小 2 秒（代码中设置为 3 秒）
- 数据线需要上拉电阻（模块版已集成）
- 工作电压 3.3-5V

#### C. 光照传感器

**方案1：BH1750（I2C数字传感器）**：
```
BH1750          ESP32
────────        ────────
VCC      ───→   3.3V
GND      ───→   GND
SCL      ───→   GPIO 22（与 OLED 共享）
SDA      ───→   GPIO 21（与 OLED 共享）
ADDR     ───→   GND（地址 0x23）
```

**方案2：光敏电阻（模拟传感器）**：
```
                   3.3V
                    │
                ┌───┴───┐
                │ 10kΩ │ 上拉电阻
                │      │
                └───┬───┘
                    │
                    ├────→ GPIO 36（AOUT）
                    │
                ┌───┴───┐
                │ 光敏  │ 光敏电阻
                │ 电阻  │ (阻值随光照变化)
                └───┬───┘
                    │
                   GND
```

**注意事项**：
- 光敏电阻方案需要分压电路
- BH1750 精度更高，光敏电阻成本更低

#### D. 水位传感器（浮球开关）

**接线**：
```
浮球开关         ESP32
────────        ────────
COM      ───→   GPIO 5
NO       ───→   3.3V（常开触点）
GND      ───→   GND（如有）
```

**工作原理**：
- 水位正常：浮球浮起，触点闭合，GPIO 5 读到 HIGH
- 水位不足：浮球下沉，触点断开，GPIO 5 读到 LOW（内部上拉）

**注意事项**：
- 使用内部上拉电阻（代码中配置 `INPUT_PULLUP`）
- 确认是**常开型**（NO，Normally Open）

### 2.2 执行器接线

#### A. 水泵 + MOS管驱动模块（×4）

**单路接线示意**：
```
        5V 电源适配器
            │
    ┌───────┴────────┐
    │                │
    │           ┌────┴────┐
    │           │  水泵1   │
    │           │  (+极)   │
    │           └────┬────┘
    │                │
    │           ┌────┴────┐
    │           │  MOS管  │
    │           │  模块   │
    │           │  V+     │
    │           └────┬────┘
    │                │
    │                │ V-
    │           ┌────┴────┐
    │           │  水泵1   │
    │           │  (-极)   │
    │           └────┬────┘
    │                │
    └────────────────┴────→ GND（公共地）

MOS管模块        ESP32
────────        ────────
VCC      ───→   5V（或不接，部分模块不需要）
GND      ───→   GND
SIG      ───→   GPIO 16（水泵1）
```

**4路完整接线**：

| MOS管模块 | ESP32 PWM 引脚 | 水泵 | 电源连接 |
|----------|---------------|------|---------|
| MOS1 SIG | GPIO 16 | 水泵1 | 5V → V+ → 水泵+ → 水泵- → V- → GND |
| MOS2 SIG | GPIO 17 | 水泵2 | 同上 |
| MOS3 SIG | GPIO 18 | 水泵3 | 同上 |
| MOS4 SIG | GPIO 19 | 水泵4 | 同上 |

**关键要点**：
- ✅ **水泵独立供电**：从 5V 电源适配器取电，不从 ESP32
- ✅ **共地连接**：ESP32 GND 与 水泵电源 GND 必须连接
- ✅ **MOS管作用**：ESP32 GPIO 输出 PWM 信号 → MOS管放大 → 驱动水泵
- ✅ **PWM调速**：通过调整 PWM 占空比（0-255）控制水泵转速

**注意事项**：
- 水泵工作电流约 100-150mA，ESP32 GPIO 最大输出仅 40mA，无法直接驱动
- MOS管模块支持 PWM 输入，实现水泵调速
- 确保电源适配器功率足够（5V 3A 或更大）

#### B. 蜂鸣器

**有源蜂鸣器接线**：
```
蜂鸣器           ESP32
────────        ────────
VCC (+ )  ───→  GPIO 23
GND (- )  ───→  GND
```

**或通过三极管驱动（可选，推荐）**：
```
               GPIO 23
                  │
              ┌───┴───┐
              │ 1kΩ  │ 基极限流电阻
              └───┬───┘
                  │
                  ├────→ NPN 三极管基极（如 S8050）
                  │
                 ┌┴┐
                 │ │ 蜂鸣器
                 │ │
                 └┬┘
                  │
                 VCC (5V)
```

**注意事项**：
- 有源蜂鸣器：直接接电源即响，GPIO 高电平时响
- 无源蜂鸣器：需 PWM 信号驱动（不推荐，本项目使用有源）

#### C. LED 指示灯

**接线**：
```
               GPIO 2
                  │
              ┌───┴───┐
              │ 220Ω │ 限流电阻
              └───┬───┘
                  │
                 ┌┴┐
                 │ │ LED（正极）
                 │ │
                 └┬┘
                  │
                 GND
```

**注意事项**：
- LED 正向压降约 2V（红色）或 3V（蓝/白色）
- 限流电阻计算：R = (3.3V - 2V) / 10mA ≈ 220Ω
- GPIO 2 通常是 ESP32 板载 LED，可直接使用

### 2.3 显示与交互接线

#### A. OLED 显示屏（I2C）

**接线**：
```
OLED模块        ESP32
────────        ────────
GND      ───→   GND
VCC      ───→   3.3V 或 5V（根据模块规格）
SCL      ───→   GPIO 22
SDA      ───→   GPIO 21
```

**注意事项**：
- I2C 地址默认 0x3C（代码中定义）
- 如果显示不正常，尝试用 I2C 扫描程序确认地址
- SDA/SCL 需要上拉电阻（OLED 模块通常已集成）
- 如果与 BH1750 共享 I2C，注意地址冲突

#### B. 按键开关

**模式按键（GPIO 15）**：
```
               GPIO 15
                  │
            ┌─────┴─────┐
            │   按键    │ 轻触开关
            │           │
            └─────┬─────┘
                  │
                 GND
```

**选择按键（GPIO 13）**：
```
               GPIO 13
                  │
            ┌─────┴─────┐
            │   按键    │ 轻触开关
            │           │
            └─────┬─────┘
                  │
                 GND
```

**工作原理**：
- 按键未按下：GPIO 通过内部上拉电阻连接到 3.3V，读到 HIGH
- 按键按下：GPIO 与 GND 短路，读到 LOW

**注意事项**：
- 代码中配置 `pinMode(pin, INPUT_PULLUP)`，启用内部上拉
- 无需外接上拉电阻
- 按键消抖在代码中通过状态机实现

## 3. 电源接线方案

### 方案 A：USB 供电（开发阶段）

```
┌────────────────┐
│ 5V 3A USB 充电器│
└────────┬───────┘
         │ Micro USB / Type-C
         ↓
┌────────────────┐
│  ESP32 开发板   │
│  (USB 接口)     │
└────────┬───────┘
         │ 板载 AMS1117 稳压
         ├────→ 3.3V 输出（供传感器）
         │
         └────→ 5V 引脚（供 MOS管模块）
```

**注意**：USB 供电时，水泵电源需要单独接线到 USB 充电器的 5V 输出。

### 方案 B：独立电源（部署阶段，推荐）

```
┌────────────────┐
│ 5V 3A 适配器    │
└────┬───────────┘
     │
 ┌───┴──┬──────┬──────┬──────┐
 │      │      │      │      │
 ↓      ↓      ↓      ↓      ↓
ESP32  MOS1   MOS2   MOS3   MOS4
VIN    V+     V+     V+     V+
 │      │      │      │      │
 │     水泵1   水泵2   水泵3   水泵4
 │      │      │      │      │
 └──────┴──────┴──────┴──────┴─→ GND（公共地）
```

**接线步骤**：
1. 5V 适配器正极 → ESP32 的 VIN 引脚
2. 5V 适配器正极 → 所有 MOS管模块的 V+ 端子
3. 5V 适配器负极 → ESP32 的 GND 引脚
4. ESP32 GND → 所有 MOS管模块的 GND
5. 所有传感器和模块的 GND 连接到 ESP32 GND（公共地）

**注意事项**：
- ✅ 所有 GND 必须连接到同一点（公共地）
- ✅ 电源适配器功率至少 5V 3A（15W）
- ❌ 不要同时使用 USB 和外部电源（会冲突）

## 5. 接线检查清单

在上电前，请逐项检查以下内容：

### 电源检查
- [ ] 5V 电源适配器功率 ≥ 15W（5V 3A）
- [ ] ESP32 VIN 引脚已连接到 5V
- [ ] 所有设备 GND 连接到公共地
- [ ] 没有短路（用万用表检查）

### 传感器检查
- [ ] 4 个土壤湿度传感器分别接到 GPIO 34/35/32/33
- [ ] DHT22 接到 GPIO 4，带上拉电阻（或模块版）
- [ ] 光照传感器接到 GPIO 36 或 I2C（GPIO 21/22）
- [ ] 水位传感器接到 GPIO 5
- [ ] 所有传感器 VCC 和 GND 正确

### 执行器检查
- [ ] 4 个 MOS管模块 SIG 分别接到 GPIO 16/17/18/19
- [ ] MOS管 V+ 接到 5V 电源
- [ ] MOS管 V- 接到水泵负极
- [ ] 水泵正极接到 5V 电源
- [ ] 蜂鸣器接到 GPIO 23
- [ ] LED 串联 220Ω 电阻接到 GPIO 2

### 显示与交互检查
- [ ] OLED SDA → GPIO 21
- [ ] OLED SCL → GPIO 22
- [ ] 按键1 → GPIO 15 → GND
- [ ] 按键2 → GPIO 13 → GND

## 6. 常见问题与排查

### Q1：土壤湿度传感器读数始终为 0 或 100%

**可能原因**：
- 传感器未插入土壤
- VCC 或 GND 接触不良
- AOUT 引脚未正确连接
- 传感器损坏

**排查方法**：
1. 用万用表测量传感器 AOUT 电压（应在 0-3.3V 之间）
2. 检查接线是否松动
3. 尝试更换传感器

### Q2：DHT22 读数为 NaN（无效）

**可能原因**：
- 数据线未接上拉电阻（裸传感器）
- GPIO 4 引脚损坏
- DHT22 损坏
- 采样间隔过短

**排查方法**：
1. 检查 DATA 引脚是否有 4.7kΩ 上拉到 VCC
2. 确认代码中采样间隔 ≥ 2 秒
3. 尝试更换 DHT22 传感器

### Q3：OLED 显示屏无显示

**可能原因**：
- I2C 地址错误（默认 0x3C）
- SDA/SCL 接反
- 电源电压不匹配
- OLED 损坏

**排查方法**：
1. 运行 I2C 扫描程序检测地址
   ```cpp
   Wire.begin(21, 22);
   Wire.beginTransmission(0x3C);
   byte error = Wire.endTransmission();
   if (error == 0) Serial.println("找到设备 0x3C");
   ```
2. 检查 VCC 是 3.3V 还是 5V（根据模块规格）
3. 尝试交换 SDA 和 SCL

### Q4：水泵不转或转速慢

**可能原因**：
- 电源功率不足
- MOS管未导通
- PWM 信号错误
- 水泵堵塞

**排查方法**：
1. 检查电源适配器功率（至少 5V 3A）
2. 用万用表测量 MOS管 SIG 引脚电压（PWM 运行时应有波动）
3. 测量水泵两端电压（应为 5V）
4. 清理水泵叶片

### Q5：按键无响应

**可能原因**：
- 按键接线错误
- 内部上拉未启用
- GPIO 引脚被占用

**排查方法**：
1. 检查按键一端接 GPIO，另一端接 GND
2. 确认代码中配置 `pinMode(pin, INPUT_PULLUP)`
3. 用万用表测量 GPIO 电平（未按下为 HIGH，按下为 LOW）

## 7. 优化建议

### 7.1 线缆管理

- 使用不同颜色杜邦线：
  - **红色**：VCC / 5V
  - **黑色**：GND
  - **黄色**：信号线（传感器）
  - **蓝色**：信号线（控制）
- 使用扎带或理线器固定线缆
- 标记每根线的功能

### 7.2 防水处理

- 土壤湿度传感器接头用热缩管密封
- 水泵电源线接头用防水接线盒
- ESP32 主板放入防水盒（留散热孔）

### 7.3 PCB 版本

如果需要更稳定的连接，建议定制 PCB：
- 使用嘉立创 EDA 设计原理图
- 集成所有接线端子
- 添加电源指示灯和保险丝
- 预留扩展接口

## 8. 总结

完整接线需要连接：
- **7 个传感器**（4×土壤湿度 + DHT22 + 光照 + 水位）
- **4 个水泵**（通过 MOS管驱动）
- **1 个 OLED 显示屏**（I2C）
- **2 个按键**
- **1 个蜂鸣器**
- **1 个 LED**

**关键要点**：
- ✅ 所有 GND 连接到公共地
- ✅ 水泵独立供电，不从 ESP32 取电
- ✅ ADC 输入电压不超过 3.3V
- ✅ I2C 上拉电阻（OLED 模块已集成）

**接线时间估计**：
- 面包板版本：1-2 小时
- PCB 焊接版本：2-4 小时

**建议**：
1. 分模块逐步接线，每接一个模块测试一次
2. 使用万用表检查电压和连通性
3. 第一次上电前仔细检查，避免短路烧毁元件
