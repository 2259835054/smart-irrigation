# 接线说明

本文档详细说明智能灌溉系统各个模块与 ESP32 的接线方法。

## ⚠️ 重要安全提示

1. **断电操作**：接线时请确保所有设备断电
2. **共地连接**：所有模块必须共地（GND 连接在一起）
3. **电压检查**：确认传感器工作电压（3.3V 或 5V）
4. **水泵供电**：水泵需要独立供电，不能直接从 ESP32 供电
5. **防水处理**：土壤湿度传感器和水位传感器需做好防水

## 引脚连接表

### ESP32 引脚分配

| 功能 | ESP32 引脚 | 引脚类型 | 备注 |
|------|-----------|---------|------|
| 土壤湿度传感器 | GPIO 34 | ADC (输入) | 只能输入，不能输出 |
| DHT22 温湿度 | GPIO 4 | 数字 I/O | 需要上拉电阻 |
| 水位传感器 | GPIO 5 | 数字输入 | 使用内部上拉 |
| 水泵控制 | GPIO 16 | 数字输出 | 驱动水泵驱动模块 |
| 按键 | GPIO 15 | 数字输入 | 使用内部上拉 |
| LED 指示灯 | GPIO 2 | 数字输出 | 板载 LED |
| 蜂鸣器 | GPIO 17 | 数字输出 | 缺水报警 |
| OLED SDA | GPIO 21 | I2C 数据 | 默认 I2C SDA |
| OLED SCL | GPIO 22 | I2C 时钟 | 默认 I2C SCL |

### 1. ESP32 开发板

ESP32 是整个系统的核心控制器。

**供电**：
- **VIN/5V**：连接 5V 电源适配器正极
- **GND**：连接电源适配器负极和所有模块的 GND

---

### 2. 电容式土壤湿度传感器

**接线**：

| 传感器引脚 | 连接到 |
|-----------|--------|
| VCC | ESP32 3.3V |
| GND | ESP32 GND |
| AOUT | ESP32 GPIO 34 |

**注意事项**：
- ✅ 使用 3.3V 供电（部分传感器支持 3.3V-5V）
- ✅ 只将金属探头部分插入土壤，电路板部分不要接触水
- ✅ 定期清洁探头，防止氧化

---

### 3. DHT22 温湿度传感器

**接线**：

| DHT22 引脚 | 连接到 |
|-----------|--------|
| VCC (1) | ESP32 3.3V |
| DATA (2) | ESP32 GPIO 4 |
| NC (3) | 不连接 |
| GND (4) | ESP32 GND |

**上拉电阻**：
- 在 DATA 引脚和 VCC 之间连接一个 **4.7kΩ 上拉电阻**
- 某些模块内置上拉电阻，可以省略外接电阻

**示意图**：
```
       3.3V
         |
        [4.7kΩ]
         |
DHT22 ---+--- GPIO 4
         |
        GND
```

**注意事项**：
- ✅ DHT22 有 4 个引脚，从左到右分别是 VCC、DATA、NC、GND
- ✅ 某些模块是 3 引脚版本（VCC、DATA、GND），无需上拉电阻

---

### 4. 水位传感器（浮球开关）

**接线**：

| 传感器引脚 | 连接到 |
|-----------|--------|
| VCC | ESP32 5V |
| GND | ESP32 GND |
| OUT | ESP32 GPIO 5 |

**工作原理**：
- 有水时：输出 **LOW**（0V）
- 缺水时：输出 **HIGH**（3.3V/5V）

**注意事项**：
- ✅ 浮球开关需要浸入水中
- ✅ 确保浮球可以自由上下移动

---

### 5. 微型水泵 + MOS 管驱动模块

**这是最关键的部分！水泵不能直接连接 ESP32！**

#### 方案 A：使用 MOS 管驱动模块（推荐）

**MOS 管模块接线**：

| MOS 管模块 | 连接到 |
|-----------|--------|
| VCC | 5V 电源 + |
| GND | 5V 电源 - 和 ESP32 GND（共地！）|
| IN | ESP32 GPIO 16 |
| V+ | 水泵 + |
| V- | 水泵 - |

**电路图**：
```
5V 电源 (+) ────┬──> MOS 模块 VCC
               │
               └──> MOS 模块 V+
                        |
                        |
                       [水泵]
                        |
5V 电源 (-) ────┬──> MOS 模块 GND ──┬──> MOS 模块 V-
               │                   │
               └───────────────────┴──> ESP32 GND

ESP32 GPIO 16 ──────────────────────> MOS 模块 IN
```

#### 方案 B：使用继电器模块

**继电器模块接线**：

| 继电器模块 | 连接到 |
|-----------|--------|
| VCC | ESP32 5V |
| GND | ESP32 GND |
| IN | ESP32 GPIO 16 |
| COM | 5V 电源 + |
| NO | 水泵 + |

水泵负极直接连接电源负极。

**注意事项**：
- ⚠️ 继电器有吸合声音，不如 MOS 管静音
- ✅ 确认是高电平触发还是低电平触发（代码默认高电平启动）

---

### 6. OLED 显示屏（SSD1306，I2C）

**接线**：

| OLED 引脚 | 连接到 |
|-----------|--------|
| VCC | ESP32 3.3V |
| GND | ESP32 GND |
| SCL | ESP32 GPIO 22 |
| SDA | ESP32 GPIO 21 |

**注意事项**：
- ✅ 确认是 I2C 接口（4 引脚），不要买成 SPI 接口（7 引脚）
- ✅ 默认 I2C 地址是 0x3C（部分是 0x3D，需修改代码）
- ✅ ESP32 的 I2C 上拉电阻通常内置，不需要外接

---

### 7. 按键开关

**接线**：

| 按键引脚 | 连接到 |
|---------|--------|
| 一端 | ESP32 GPIO 15 |
| 另一端 | ESP32 GND |

**工作原理**：
- GPIO 15 配置为 `INPUT_PULLUP`（内部上拉）
- 按下时：GPIO 15 = LOW
- 松开时：GPIO 15 = HIGH

**注意事项**：
- ✅ 使用内部上拉电阻，无需外接电阻
- ✅ 轻触开关通常有 4 个引脚，对角线的引脚是连通的

---

### 8. LED 指示灯

**接线**：

| LED 引脚 | 连接到 |
|---------|--------|
| 正极（长脚）| 220Ω 电阻 → ESP32 GPIO 2 |
| 负极（短脚）| ESP32 GND |

**电路图**：
```
GPIO 2 ──[220Ω]──>|─── GND
                 LED
```

**注意事项**：
- ✅ LED 正负极不能接反
- ✅ 电阻值 220Ω - 1kΩ 均可
- ✅ ESP32 的 GPIO 2 通常有板载 LED，可以省略外接 LED

---

### 9. 蜂鸣器（有源蜂鸣器）

**接线**：

| 蜂鸣器引脚 | 连接到 |
|-----------|--------|
| + (VCC) | ESP32 GPIO 17 |
| - (GND) | ESP32 GND |

**注意事项**：
- ✅ 使用有源蜂鸣器，通电即响
- ✅ 不要用无源蜂鸣器（需要 PWM 驱动）
- ✅ 正负极不能接反

---

## 接线检查清单

在上电前，请检查以下项目：

- [ ] 所有模块的 GND 已连接在一起（共地）
- [ ] 传感器供电电压正确（3.3V 或 5V）
- [ ] DHT22 数据线有上拉电阻（或模块自带）
- [ ] 水泵通过驱动模块供电，没有直接连接 ESP32
- [ ] LED 串联了限流电阻
- [ ] OLED 使用 I2C 接口（4 引脚）
- [ ] 所有引脚连接正确，无短路
- [ ] 电源适配器电流足够（≥2A）

## 常见问题

### Q1: OLED 无显示？
- 检查 I2C 地址是否正确（0x3C 或 0x3D）
- 检查 SDA 和 SCL 是否接反
- 检查供电是否正常

### Q2: DHT22 读取失败（NaN）？
- 检查是否有上拉电阻
- 检查供电是否稳定
- 等待 2 秒后再读取（DHT22 需要预热）

### Q3: 水泵不工作？
- 检查驱动模块供电
- 检查共地是否连接
- 测试 GPIO 16 输出是否正常
- 检查水泵本身是否正常

### Q4: 土壤湿度读数不正常？
- 检查传感器是否插入土壤
- 检查传感器供电
- 校准传感器（在代码中调整映射参数）
