## 一、首先回答最重要的问题：校验和为什么不能还原？

### 1.1 校验和的本质——"单向指纹"

回顾之前的讨论：把 `12345678` 切成4块（`12`、`34`、`56`、`78`）相加得到 `180`，再把进位加回去得到 `81`。

你问的是："`81` 和 `12345678` 有什么关系？我怎么还原回去？"

**答案：你永远还原不回去。这是校验和算法的核心设计。**

用生活中的比喻来理解：

> 假设你今天吃了早饭（2元）、午饭（10元）、下午茶（3元）、晚饭（20元），你算出来今天花了 **35元**。
>
> 现在只告诉别人"我今天花了35元"，别人能知道你具体吃了什么、花了几顿饭吗？
>
> **不能！** 因为很多组合都能凑出35元（比如 15+20，或者 5+5+5+20）。

校验和正是这样：它是一个**"摘要"**（Summary），**多对一**的函数——很多不同的原始数据，都可能算出同一个校验码。

### 1.2 校验和用来干什么？（错误检测，而非数据存储）

校验和的唯一作用是**发现数据在传输中有没有出错**，而不是用来存储或还原数据。

通信过程如下：

```
【发送方】                           【接收方】
原始数据: 12345678         →→→→→→    收到的数据: 12345678
校验和:   0x0051           →→→→→→    重新计算校验和: 0x0051

                            比较两个校验和是否相同
                            ✅ 相同 → 数据完整，没有出错
                            ❌ 不同 → 数据在传输中出错了，请重发！
```

**原始数据 `12345678` 已经完整传过去了。** 校验和 `0x0051` 只是一个"配套验证码"，就像快递单号旁边的条形码，让收件人能确认包裹没有在路上被掉包。

### 1.3 智能灌溉项目中的实际应用

在本智能灌溉系统里，ESP32 通过 MQTT 协议向服务器发送传感器数据（土壤湿度、温度等）。MQTT 协议底层的 TCP/IP 数据包中，就包含了类似的校验和字段，用于确保传感器读数在 WiFi 传输过程中没有因为信号干扰而产生误码。

```
智能灌溉 ESP32               WiFi 路由器              MQTT 服务器
    │                             │                        │
    │  发送 MQTT 数据包            │                        │
    │  [湿度=65%, 校验=0xABCD]  →→│→→→→→→→→→→→→→→→→→→→→→│
    │                             │                        │
    │                             │  验证校验和是否正确      │
    │                             │  ✅ 正确 → 接受数据     │
    │                             │  ❌ 错误 → 要求重传     │
```

### 2.1 第一题：信号生成与采样（MATLAB）

**题目本质：** 把数学公式写成代码，理解"模拟信号→数字信号"的采样过程。

**核心概念：**

| 概念 | 含义 | 比喻 |
|------|------|------|
| 采样频率 `Fs = 1000 Hz` | 每秒钟记录 1000 个数据点 | 每秒拍 1000 张照片 |
| 时间向量 `t` | 每张照片对应的时刻 | 快门按下的时间戳 |
| `sin(2πft)` | 频率为 f 的正弦波信号 | 某种频率的声音波形 |
| 稀疏采样 | 每隔 100 个点取一个 | 每 0.1 秒取一张照片 |

**MATLAB 完整代码（带详细注释）：**

```matlab
% =========================================================
% 第一题：基础信号生成与采样
% =========================================================

Fs = 1000;      % 采样频率：每秒采 1000 个点
T  = 1;         % 信号时长：1 秒

% 生成时间轴：从 0 开始，每步走 1/1000 秒，到 0.999 秒
% 共 1000 个时刻点（对应 1000 次采样）
t = 0 : 1/Fs : T - 1/Fs;

f1 = 60;    % 信号1的频率：60 Hz
f2 = 80;    % 信号2的频率：80 Hz

% 生成复合信号（两个信号叠加）
% 注意：公式里必须写 2*pi*f，不能只写 f
% 原因：sin() 函数的参数是"角频率"（弧度/秒），而不是频率（次/秒）
%       1 Hz = 2π 弧度/秒，所以必须乘以 2π
x = sin(2*pi*f1*t) + cos(2*pi*f2*t);

% ---- 小问(2)：取索引 0, 100, 200, ..., 900 的采样点 ----
% 注意陷阱：题目说"索引0"，但MATLAB从1开始计数！
%           索引 0   → MATLAB中是第 1   个元素
%           索引 100 → MATLAB中是第 101 个元素
%           以此类推，需要整体 +1
idx = (0:100:900) + 1;      % [1, 101, 201, ..., 901]
disp('=== 稀疏采样结果（10个点）===');
disp(x(idx));

% ---- 小问(3)：打印前10项（索引 0 到 9）----
% 索引 0~9 → MATLAB中是第 1~10 个元素
disp('=== 前十项输出（索引 0 到 9）===');
disp(x(1:10));
```

**为什么 `sin()` 里要写 `2*pi*f`？**

```
物理上：f = 60 Hz 表示信号每秒振动 60 次
数学上：sin(θ) 中 θ 是弧度，振动一次需要走完 2π 弧度
所以：1秒内走完 60×2π 弧度 → sin(2π×60×t) = sin(2πf×t)
```

### 2.2 第二题：周期相移叠加法（MATLAB）

**题目本质：** 利用"多次叠加、随机抵消"的原理，从强噪声中把弱信号挖出来。

**核心原理（KTV比喻）：**

```
目标：录下朋友在嘈杂KTV中唱的一句歌词

方法：让朋友同样的歌词唱400遍，把400次录音叠加
结果：
  ✅ 朋友的声音：每次都一样 → 400次叠加后，幅度变成 400 倍
  ❌ 背景噪音：每次随机变化 → 400次叠加后，正负相消，只增长约 20 倍（√400）

信噪比提升：400/20 = 20 倍 → 约 26 dB（超过了25 dB的要求）
```

**MATLAB 完整代码（含 `awgn` 函数用法）：**

```matlab
% =========================================================
% 第二题：周期相移叠加法提取弱信号
% =========================================================

Fs = 1000;              % 采样频率 1000 Hz
f0 = 10;                % 弱信号频率 10 Hz
N_per = Fs / f0;        % 每个周期的采样点数 = 1000/10 = 100 点
M  = 400;               % 叠加次数（周期数）

% 生成 400 个周期的时间轴（共 40000 个点）
t = (0 : M*N_per - 1) / Fs;

% 生成纯净的弱正弦信号
s = sin(2*pi*f0*t);

% ---- 加噪声：使输入信噪比为 -10 dB ----
% 方法一：使用内置函数（推荐，代码简洁）
%   'measured' 让 MATLAB 自动测量信号 s 的功率，再按 -10dB 加噪
x_noisy = awgn(s, -10, 'measured');

% 方法二：手动计算（帮助理解原理）
% snr_db = -10;
% Ps    = var(s);                        % 信号功率（方差）
% Pn    = Ps / 10^(snr_db/10);          % 噪声功率
% noise = sqrt(Pn) * randn(size(s));    % 生成高斯白噪声
% x_noisy = s + noise;

% ---- 核心：叠加滤波 ----
% 把 40000 点的长数组切成 400 段，每段 100 点
% reshape(向量, 行数, 列数) → 变成一个矩阵
x_mat = reshape(x_noisy, N_per, M);  % 100行 × 400列

% 对每一行（同一周期内相同位置的点）取平均
% mean(矩阵, 2) 表示沿第2个维度（列方向）求均值，结果是列向量
x_filtered = mean(x_mat, 2)';        % 转置为行向量，得到1个周期的纯净信号

% ---- 验证结果 ----
x_out = repmat(x_filtered, 1, M);    % 扩展回原长度，便于与原信号对比
snr_out = snr(s, x_out - s);         % 使用内置 snr() 函数计算信噪比
fprintf('输入信噪比：-10.00 dB\n');
fprintf('输出信噪比：%.2f dB\n', snr_out);
% 预期输出约：+15 dB（达到题目要求）
```

### 2.3 第三题：64位分组进位校验码（C语言 vs MATLAB 完整对照）

#### 3.1 算法步骤图解（用十进制举例）

以 `12345678` 为例，按题目要求每2位切一组：

```
原始数据：  1  2  3  4  5  6  7  8
           ├──┤  ├──┤  ├──┤  ├──┤
第1组:        12
第2组:           34
第3组:              56
第4组:                 78
                          ↓
                       相加：12 + 34 + 56 + 78 = 180
                          ↓
                     180 超过了2位数的最大值99，发生进位
                     高位部分：180 ÷ 100 的商 = 1（进位）
                     低位部分：180 mod 100    = 80
                          ↓
                     把进位加回低位：80 + 1 = 81
                          ↓
                     81 ≤ 99，不再进位，结束
                          ↓
                    最终校验码 = 81
```

在真实计算机里：
- 原始数据是 **64位**（不是8位数字）
- 每组是 **16位**（不是2位数字）
- "最大值"是 **0xFFFF = 65535**（不是99）
- 其他规则完全一样！

#### 3.2 C语言 vs MATLAB 逐行对照表

| 步骤 | C 语言 | MATLAB |
|------|--------|--------|
| 声明64位变量 | `uint64_t data = 0x...;` | `data = uint64(0x...);` |
| 声明32位累加器 | `uint32_t sum = 0;` | `sum_val = uint32(0);` |
| 向右移位 N 位 | `data >> N` | `bitshift(data, -N)` |
| 保留最低16位 | `data & 0xFFFF` | `bitand(data, 0xFFFF)` |
| 判断溢出 | `while (sum > 0xFFFF)` | `while sum_val > 0xFFFF` |
| 最终类型转换 | `(uint16_t)sum` | `uint16(sum_val)` |

#### 3.3 C语言完整代码

```c
#include <stdio.h>
#include <stdint.h>

/**
 * @brief 产生16位校验码（反码求和算法）
 *        广泛用于 TCP/IP 协议的数据包校验
 *
 * 算法步骤：
 *   1. 将64位数据切成4个16位组
 *   2. 用32位变量累加（防止溢出丢失进位）
 *   3. 把累加结果高16位的进位折回到低16位
 *   4. 返回低16位作为校验码
 */
uint16_t generate_checksum(uint64_t data) {
    uint32_t sum = 0;

    /* 步骤1：切成4段，每段16位，全部加进 sum */
    sum += (data >> 48) & 0xFFFF;   /* 取最高的16位 */
    sum += (data >> 32) & 0xFFFF;   /* 取第2段16位  */
    sum += (data >> 16) & 0xFFFF;   /* 取第3段16位  */
    sum += (data       ) & 0xFFFF;  /* 取最低的16位 */

    /* 步骤2：循环折叠进位，直到结果能放进16位 */
    while (sum >> 16) {
        sum = (sum & 0xFFFF)   /* 低16位 */
            + (sum >> 16);     /* 进位部分折回低位 */
    }

    return (uint16_t)sum;
}

int main(void) {
    uint64_t my_data = 0x123456789ABCDEF0ULL;
    uint16_t checksum = generate_checksum(my_data);

    printf("原始64位数据  : 0x%016llX\n", (unsigned long long)my_data);
    printf("16位校验码    : 0x%04X\n", checksum);
    return 0;
}
```

#### 3.4 MATLAB完整代码

```matlab
% =========================================================
% 第三题：64位分组进位校验码（MATLAB 版本）
% =========================================================

% 声明64位无符号整数（必须用 uint64 包裹，否则 MATLAB 当浮点数处理）
my_data = uint64(0x123456789ABCDEF0);

% ---- 步骤1：切成4段，每段16位，存入32位累加器 ----
% bitshift(x, -N) 相当于 C 语言的 x >> N
% bitand(x, 0xFFFF) 相当于 C 语言的 x & 0xFFFF
sum_val = uint32(0);
sum_val = sum_val + uint32(bitand(bitshift(my_data, -48), 0xFFFF));
sum_val = sum_val + uint32(bitand(bitshift(my_data, -32), 0xFFFF));
sum_val = sum_val + uint32(bitand(bitshift(my_data, -16), 0xFFFF));
sum_val = sum_val + uint32(bitand(my_data,              0xFFFF));

% ---- 步骤2：循环折叠进位 ----
while sum_val > 0xFFFF
    carry   = bitshift(sum_val, -16);       % 高位（进位部分）
    lower16 = bitand(sum_val, 0xFFFF);      % 低16位
    sum_val = lower16 + carry;              % 折叠
end

% ---- 输出结果 ----
checksum = uint16(sum_val);
fprintf('原始64位数据 : %016X\n', my_data);
fprintf('16位校验码   : %04X\n',  checksum);
```

## 三、核心知识点速查手册

### 3.1 位操作速查表（C语言）

| 操作 | 符号 | 例子 | 结果 | 用途 |
|------|------|------|------|------|
| 左移 | `<<` | `1 << 4` | `16` | 快速乘以2的幂 |
| 右移 | `>>` | `256 >> 4` | `16` | 快速除以2的幂，或"取高位" |
| 按位与 | `&` | `0xFF & 0x1234` | `0x34` | 提取低位（掩码） |
| 按位或 | `|` | `0xF0 | 0x0F` | `0xFF` | 设置某些位为1 |
| 按位异或 | `^` | `0xFF ^ 0x0F` | `0xF0` | 翻转某些位 |
| 按位取反 | `~` | `~0x00FF` | `0xFF00` | 所有位取反 |

**实用记忆法：**
- `& 0xFFFF` = "保留低16位，其余清零" → 就像用筛子筛掉上面的部分
- `>> 16` = "把高16位移到低位" → 就像把高层的内容挪到地面
- "先移位，再掩码" 是取任意位段的万能公式

### 3.2 MATLAB 信号处理函数速查表

| 功能 | 函数 | 例子 |
|------|------|------|
| 加白噪声 | `awgn(s, snr, 'measured')` | 加 -10dB 噪声 |
| 计算信噪比 | `snr(signal, noise)` | 返回 dB 值 |
| 快速傅里叶变换 | `fft(x)` | 分析频域成分 |
| 重塑数组 | `reshape(x, rows, cols)` | 切段排列 |
| 沿维度求平均 | `mean(M, 2)` | 按列取平均 |
| 重复复制 | `repmat(v, 1, M)` | 横向复制M次 |
| 功率谱密度 | `pwelch(x, [], [], [], Fs)` | 频谱分析 |

### 3.3 信噪比 (SNR) 计算公式

$$\text{SNR (dB)} = 10 \log_{10} \left( \frac{P_{\text{signal}}}{P_{\text{noise}}} \right)$$

| SNR | 含义 |
|-----|------|
| < 0 dB | 噪声比信号还大，完全淹没 |
| 0 dB | 信号和噪声能量相等 |
| +10 dB | 信号功率是噪声的10倍 |
| +20 dB | 信号功率是噪声的100倍，很清晰 |

叠加 $M$ 个周期后 SNR 提升量：$\Delta\text{SNR} = 10\log_{10}(M)$

例：从 -10 dB 提升到 +15 dB，需要提升 25 dB，所以 $M = 10^{2.5} \approx 316$，取 400 留余量。

## 五、考场应试技巧

### 5.1 看到信号处理题的答题思路

```
1. 确认采样频率 Fs 和信号频率 f
   → 验证奈奎斯特定理：Fs > 2f（否则会混叠）

2. 生成时间轴：t = 0 : 1/Fs : T-1/Fs
   → 注意 MATLAB 索引从1开始！

3. 生成信号：一定要写 sin(2*pi*f*t)，不要漏掉 2*pi

4. 如果题目说"提升信噪比"，想到叠加平均法
   → M 次叠加提升 10*log10(M) dB
```

### 5.2 看到位操作题的答题思路

```
1. 确认数据总位宽（本题64位）和分组位宽（本题16位）

2. 提取第 k 组（从高位到低位，k从0开始）：
   (data >> (总位宽 - (k+1)*分组位宽)) & 掩码

3. 进位处理：用 while (sum > 掩码) 循环
   → 每次循环：sum = (sum & 掩码) + (sum >> 分组位宽)

4. 返回结果时注意类型转换：(uint16_t)sum
```

### 5.3 常见错误与避坑

| 错误 | 原因 | 正确做法 |
|------|------|----------|
| MATLAB 数组越界 | 忘记+1，用了0-based索引 | `x(n+1)` 而不是 `x(n)` |
| 信号频率不对 | 忘记乘 `2*pi` | `sin(2*pi*f*t)` |
| C语言校验溢出丢失 | 用 `uint16_t` 存中间和 | 必须用 `uint32_t` 存 `sum` |
| MATLAB 整数运算出错 | 没有声明 `uint64` | 必须用 `uint64()` 包裹 |
| 位移方向搞反 | `bitshift(x, +N)` 是左移 | 右移用负数：`bitshift(x, -N)` |
